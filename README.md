# Opulent Farms Pool Party RSVP

An interactive, responsive RSVP web application for the Opulent Farms Pool Party in Gurugram.

## Features
- **Dynamic Theme/Variant Switcher**: Switch between "Friends" and "Office" editions.
- **Interactive Wizard**: Step-by-step RSVP questionnaire with real-time progress bar.
- **Responsive Layout**: Designed for mobile, tablet, and desktop viewports.
- **Modern Styling**: Vibrant glassmorphism aesthetic with fluid animations.

## Live Demo
Deployed via GitHub Pages: [https://anshuljoshi07.github.io/pool-party-rsvp/](https://anshuljoshi07.github.io/pool-party-rsvp/)

## Project Structure
```
pool-party-rsvp/
├── index.html        # Main HTML entry point
├── css/              # Stylesheets (main.css, responsive.css)
├── js/               # App scripts (config.js, submit.js, app.js)
└── assets/           # Images & static assets
```

## Running Locally
Simply open `index.html` in any web browser or serve it using a local HTTP server:
```bash
npx serve .
```
